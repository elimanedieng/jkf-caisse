Exportez ventes, dépenses et produits en fichier JSON. Importez ce fichier sur un autre appareil pour y restaurer les données.

Effacer les données locales

Supprime toutes les opérations et tous les produits enregistrés dans ce navigateur. Le mot de passe sera exigé avant l’effacement. Cette action est irréversible sans sauvegarde.

Important : GitHub Pages héberge l'application, mais ne synchronise pas automatiquement les données entre téléphones et ordinateurs. Chaque navigateur conserve ses propres données. Utilisez la sauvegarde/importation pour transférer les données, ou ajoutez une base de données en ligne si vous souhaitez une synchronisation automatique.
